R3 - Workflow Architecture

Autonomous Research Report Generator | Multi-Agent LangGraph Pipeline

Web Application Layer
🌐
Browser
User enters topic + selects number of analysts
⚡
FastAPI + ReportService
Routes request to LangGraph workflow
Triggers LangGraph Pipeline
LangGraph - Main Research Graph
▶️
START
🧠
Create Analysts
LLM generates analyst personas with unique perspectives using structured output
👤
Human Feedback
Graph pauses here (interrupt_before). User can refine analyst selection.
Send() — one per analyst (parallel fan-out)
Interview Sub-Graph (per analyst)
❓
Ask Question
Analyst asks expert a targeted question
🔍
Search Web
Tavily API searches for relevant sources
💬
Generate Answer
Expert answers using web search context
💾
Save Interview
Stores full interview transcript
📝
Write Section
LLM writes a report section from the interview
Runs once for each analyst persona (fan-out with Send())
⚡ PARALLEL EXECUTION
📄
Write Report
Compiles all sections into unified content
📖
Write Introduction
Creates a compelling intro for the report
🔚
Write Conclusion
Summarizes key takeaways
All three must complete before continuing
📋
Finalize Report
Combines intro + content + conclusion + sources into final report
✅
END
Returns final report to ReportService
